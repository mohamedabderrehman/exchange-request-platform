# النشر وحل المشكلات

## التاريخ

واجهة استقبال طلبات بخادم PHP وTelegram. لا تنفذ تحويلاً آلياً ولا تقدم بيانات سوق مباشرة.

## البيئة المحلية

استخدم PHP 8.1 أو أحدث مع fileinfo وفك الصور وcURL. العرض مفعل افتراضياً دون مفتاح Telegram. صدّر قيم .env.example للوضع الحي مع DEMO_MODE=0 وبيانات Telegram جديدة في الخادم فقط. اختر العملات من currency-options.json وأدخل مستلمين وصور إثبات اصطناعية فقط؛ الأسعار الثابتة تقديرات عرض.

## تشخيص الأعطال

ابدأ بالتأكد من إصدار اللغة والامتدادات وتثبيت القفل، ثم اتصال قاعدة البيانات وترتيب مخططها ومتغيرات العملية. افحص عنوان API من الجهاز الفعلي لا عنوان localhost الخاص بجهاز آخر. شغل PHP للمسارات الديناميكية والموجه المحلي المرفق حيث يوجد؛ لا ينفذ خادم ثابت ملفات PHP. أبق تحقق TLS فعالاً، ولا تعالج فشل المزود بإظهار نجاح. لا تعِد إرسال نتائج غير مؤكدة دون مراجعة. في Windows أوقف العملية التي تستخدم مخرجات البناء أو محرك Prisma قبل الاستعادة.

يعرف الإيصال استقبال الطلب ولا يثبت التنفيذ المالي. التتبع العام عرض تاريخي دون سجل عمليات حي. يلزم فحص صورة إثبات صحيحة وفشل المزود قبل استقبال طلبات حقيقية.

حذف مفتاح من الشيفرة لا يلغيه عند المزود. يجب تدوير بيانات النشر القديمة بشكل مستقل؛ لم يُثبت تدويرها في هذا العمل.
