# التحقق من الإصدار الحالي

سجل 2026-10-06 ببيانات محلية مؤقتة. النشر التاريخي معلومة مستقلة قدمها المالك.

## الفحوص المحلية الناجحة

نجحت صياغة PHP وفحوص استقبال طلب اصطناعي بلا صورة ورفض مبلغ غير صالح أو صفر أو غير محدود ورفض عملة غير مدعومة ومحتوى صورة مزيف. تحقق TLS مفعل في الشيفرة. لا ندعي إرسالاً حياً أو تنفيذ تحويل مالي.

## الأوامر

```sh
php -S 127.0.0.1:8085
# Open /Exchange.html; separate terminal:
python tools/check-syntax.py
python tools/check-demo.py
```

## حالة CI

سُجلت مسارات GitHub Actions لكن المحاولات الأولى انتهت بـstartup_failure قبل إنشاء أي وظيفة أو ملاحظة فحص. النتائج المحلية أعلاه مستقلة عن CI. لا نعرض شارة نجاح ولم توفر الواجهة المتاحة سبباً تفصيلياً.

## حدود المنصة والتغطية

يعرف الإيصال استقبال الطلب ولا يثبت التنفيذ المالي. التتبع العام عرض تاريخي دون سجل عمليات حي. يلزم فحص صورة إثبات صحيحة وفشل المزود قبل استقبال طلبات حقيقية.

استُخدم PHP 8.4.26 وNode 24.19 وPython 3.12.10 حيث ينطبق. لا يثبت السجل جاهزية إنتاج شاملة أو فحص مزود مدفوع أو جميع المنصات.
